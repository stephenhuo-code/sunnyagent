## 4. ContextManager 架构详图

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│                          ContextManager Architecture                               │
├────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │                          ContextManager                                      │   │
│  │                                                                              │   │
│  │  配置:                                                                       │   │
│  │  • CONTEXT_EXPIRATION_DAYS = 7 (滑动过期)                                   │   │
│  │  • CONTEXT_CACHE_SIZE = 100 (LRU缓存大小)                                   │   │
│  │  • SHORT_CONTEXT_THRESHOLD = 2000 tokens (摘要阈值)                         │   │
│  │                                                                              │   │
│  └─────────────────────────────────────────────────────────────────────────────┘   │
│                                                                                     │
│  Public API                                                                         │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │                                                                              │   │
│  │  store(context_id, thread_id, content, expected_output, metadata)           │   │
│  │    │                                                                         │   │
│  │    ├─ 1. _estimate_tokens(content)                                          │   │
│  │    ├─ 2. _classify_output_types(content) → ["financial_report", "table"]   │   │
│  │    ├─ 3. _extract_file_references(content) → [{file_id, filename, url}]    │   │
│  │    ├─ 4. if tokens > 2000: _generate_summary() + _extract_key_data()        │   │
│  │    ├─ 5. Add to LRU cache                                                   │   │
│  │    └─ 6. _save_to_db() (PostgreSQL persistence)                             │   │
│  │                                                                              │   │
│  │  get(context_id, thread_id) → ContextEntry | None                           │   │
│  │    │                                                                         │   │
│  │    ├─ 1. Check LRU cache first                                              │   │
│  │    ├─ 2. Cache miss → _load_from_db()                                       │   │
│  │    ├─ 3. Validate thread_id (安全隔离)                                      │   │
│  │    ├─ 4. Check expiration                                                   │   │
│  │    └─ 5. touch() → Sliding expiration                                       │   │
│  │                                                                              │   │
│  │  prepare_for_task(task_description, depends_on, thread_id, expected_input)  │   │
│  │    │                                                                         │   │
│  │    ├─ 1. For each dependency: get(dep_id, thread_id)                        │   │
│  │    ├─ 2. Check I/O type matching (expected_input ∩ output_types)           │   │
│  │    ├─ 3. Select content: 全文 / 摘要 / 截断 (based on token budget)         │   │
│  │    ├─ 4. Add file references section (确保文件链接不丢失)                   │   │
│  │    └─ 5. Return formatted context string                                    │   │
│  │                                                                              │   │
│  │  cleanup_thread(thread_id) → 清理会话所有上下文                              │   │
│  │  cleanup_expired() → 清理过期上下文                                          │   │
│  │                                                                              │   │
│  └─────────────────────────────────────────────────────────────────────────────┘   │
│                                                                                     │
│  Data Model: ContextEntry                                                           │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │                                                                              │   │
│  │  context_id: str         # 任务ID (主键)                                    │   │
│  │  thread_id: str          # 会话ID (外键)                                    │   │
│  │  content: str            # 原始输出内容                                     │   │
│  │  summary: str | None     # LLM生成摘要 (长上下文)                           │   │
│  │  key_data: dict | None   # 结构化关键数据                                   │   │
│  │  output_types: list[str] # 自动分类: ["file", "table", "analysis_report"]  │   │
│  │  expected_output: list   # SubtaskSpec声明的期望输出                        │   │
│  │  token_count: int        # 估算token数                                      │   │
│  │  created_at: datetime                                                        │   │
│  │  last_accessed_at: datetime  # 滑动过期基准                                 │   │
│  │  expires_at: datetime    # 过期时间                                         │   │
│  │  metadata: dict          # 扩展信息 {actor, duration_ms, file_references}  │   │
│  │                                                                              │   │
│  └─────────────────────────────────────────────────────────────────────────────┘   │
│                                                                                     │
│  Storage Architecture                                                               │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │                                                                              │   │
│  │         Hot Path                              Cold Path                      │   │
│  │    ┌──────────────────┐               ┌──────────────────┐                  │   │
│  │    │   LRU Cache      │               │   PostgreSQL     │                  │   │
│  │    │  (OrderedDict)   │               │  task_contexts   │                  │   │
│  │    │                  │               │                  │                  │   │
│  │    │  • 快速读取      │◄─────────────▶│  • 持久化存储    │                  │   │
│  │    │  • 最近100条     │  cache miss   │  • 会话恢复      │                  │   │
│  │    │  • 自动淘汰      │  → load       │  • 滑动过期      │                  │   │
│  │    └──────────────────┘               └──────────────────┘                  │   │
│  │                                                                              │   │

```

│                        File Reference Processing Flow                              │
├────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
│  Task 1: 生成Excel文件                                                              │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ Agent Output:                                                         │          │
│  │                                                                       │          │
│  │ "已生成报表，下载链接:                                                  │          │
│  │  [📥 点击下载 report.xlsx](/api/files/abc123/report.xlsx)"            │          │
│  │                                                                       │          │
│  └───────────────────────────────┬──────────────────────────────────────┘          │
│                                  │                                                  │
│                                  ▼                                                  │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ ContextManager.store()                                                │          │
│  │                                                                       │          │
│  │ 1. _extract_file_references(content)                                  │          │
│  │    → 正则匹配: \[.*?\]\(/api/files/([^/]+)/([^)]+)\)                  │          │
│  │    → 返回: [{"file_id": "abc123",                                     │          │
│  │              "filename": "report.xlsx",                               │          │
│  │              "url": "/api/files/abc123/report.xlsx"}]                 │          │
│  │                                                                       │          │
│  │ 2. enriched_metadata["file_references"] = file_refs                   │          │
│  │                                                                       │          │
│  │ 3. if "file" not in output_types: output_types.append("file")        │          │
│  │                                                                       │          │
│  └───────────────────────────────┬──────────────────────────────────────┘          │
│                                  │                                                  │
│                                  ▼                                                  │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ ContextEntry Stored:                                                  │          │
│  │                                                                       │          │
│  │ {                                                                     │          │
│  │   "context_id": "task-1-uuid",                                        │          │
│  │   "content": "已生成报表...",                                         │          │
│  │   "output_types": ["file", "table"],                                  │          │
│  │   "metadata": {                                                       │          │
│  │     "actor": "generic",                                               │          │
│  │     "file_references": [                                              │          │

│  │     ]                                                                 │          │
│  │   }                                                                   │          │
│  │ }                                                                     │          │
│  └──────────────────────────────────────────────────────────────────────┘          │
│                                                                                     │
│  Task 2: 需要Task 1的文件 (depends_on: ["task-1-uuid"])                            │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ ContextManager.prepare_for_task()                                     │          │
│  │                                                                       │          │
│  │ 生成上下文 (即使原内容被摘要，文件链接也会保留):                         │          │
│  │                                                                       │          │
│  │ ### 前置任务输出 (摘要) [类型: file, table]                            │          │
│  │ {摘要内容}                                                            │          │
│  │                                                                       │          │

## 7. Plan 模式执行流程

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│                          Plan Mode Execution Flow                                   │
├────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
│  User: "分析特斯拉2023年财报，然后生成PPT"                                          │
│       │                                                                             │
│       ▼                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │ IntentAnalyzer → action: "plan", capabilities: ["web_search", "file_gen"]   │   │
│  └─────────────────────────────────────────────────────────────────────────────┘   │
│       │                                                                             │
│       ▼                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │ _decompose_task() → LLM分解                                                 │   │
│  │                                                                              │   │
│  │ [                                                                            │   │
│  │   {                                                                          │   │
│  │     "id": "step_1",                                                          │   │
│  │     "description": "搜索特斯拉2023年财报数据",                               │   │
│  │     "capabilities": ["web_search"],                                          │   │
│  │     "depends_on": [],                                                        │   │
│  │     "expected_output": ["financial_report", "revenue_data"]                  │   │
│  │   },                                                                         │   │
│  │   {                                                                          │   │
│  │     "id": "step_2",                                                          │   │
│  │     "description": "基于财报数据生成分析PPT",                                │   │
│  │     "capabilities": ["file_generation"],                                     │   │
│  │     "depends_on": ["step_1"],                                                │   │
│  │     "expected_input": ["financial_report"],                                  │   │
│  │     "expected_output": ["file"]                                              │   │
│  │   }                                                                          │   │
│  │ ]                                                                            │   │
│  └─────────────────────────────────────────────────────────────────────────────┘   │
│       │                                                                             │
│       ▼                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────────────┐   │
│  │ Execution Loop                                                               │   │
│  │                                                                              │   │
│  │ Round 1: step_1 ready (no dependencies)                                     │   │
│  │ ┌───────────────────────────────────────────────────────────────────────┐   │   │
│  │ │ 1. ActorFactory.select_actor(step_1) → Research Agent                 │   │   │
│  │ │ 2. progress_manager.start_task("step_1")                              │   │   │
│  │ │ 3. _execute_actor(actor, message, user_id=self._current_user_id)      │   │   │
│  │ │ 4. Collect result_text                                                 │   │   │
│  │ │ 5. context_manager.store("step_1", thread_id, result_text)            │   │   │
│  │ │ 6. progress_manager.complete_task("step_1")                           │   │   │
│  │ └───────────────────────────────────────────────────────────────────────┘   │   │
│  │                                                                              │   │
│  │ Round 2: step_2 ready (step_1 completed)                                    │   │
│  │ ┌───────────────────────────────────────────────────────────────────────┐   │   │
│  │ │ 1. context_manager.prepare_for_task(depends_on=["step_1"])            │   │   │
│  │ │    → 获取step_1的输出作为上下文                                        │   │   │
│  │ │                                                                        │   │   │
│  │ │ 2. Build task_message:                                                 │   │   │
│  │ │    "{description}                                                      │   │   │
│  │ │                                                                        │   │   │
│  │ │    ## 上下文信息（来自前置任务的输出）                                  │   │   │
│  │ │    ### 前置任务输出 (全文) [类型: financial_report]                    │   │   │
│  │ │    {step_1 output}                                                     │   │   │
│  │ │                                                                        │   │   │
│  │ │    ## 注意                                                             │   │   │
│  │ │    请基于上述上下文信息完成当前任务..."                                 │   │   │
│  │ │                                                                        │   │   │
│  │ │ 3. ActorFactory.select_actor(step_2) → Generic Agent                  │   │   │
│  │ │ 4. _execute_actor(actor, task_message, user_id=...)                   │   │   │
│  │ │ 5. context_manager.store("step_2", ...)                               │   │   │
│  │ │ 6. progress_manager.complete_task("step_2")                           │   │   │
│  │ └───────────────────────────────────────────────────────────────────────┘   │   │
│  │                                                                              │   │
│  │ All completed → _generate_summary()                                          │   │
│  └─────────────────────────────────────────────────────────────────────────────┘   │
│                                                                                     │
└────────────────────────────────────────────────────────────────────────────────────┘
```

## 8. 核心组件职责表

| 组件 | 文件 | 主要职责 | 输入 | 输出 |
|------|------|----------|------|------|
| **AIMEPlanner** | `planner.py` | 主入口，协调意图分析和任务执行 | User message + context | SSE events |
| **IntentAnalyzer** | `intent/analyzer.py` | 用户意图分类 | Message | IntentResult |
| **ActorFactory** | `actor_factory.py` | Agent选择和配置 | SubtaskSpec | Actor |
| **ProgressManager** | `progress_manager.py` | 任务状态追踪 | Task events | State updates |
| **ContextManager** | `context_manager.py` | 任务间上下文传递 | Task outputs | Context strings |
| **StreamHandler** | `stream_handler.py` | LangGraph→SSE转换 | Graph events | SSE events |

## 10. SSE 事件类型

| 事件 | 触发条件 | 数据结构 |
|------|----------|----------|
| `thinking` | 路由/规划决策 | `{content, type: "routing"|"planning"|"replanning"}` |
| `task_spawned` | 任务创建 | `{task_id, subagent_type, description, status: "pending"}` |
| `task_started` | 任务开始执行 | `{task_id}` |
| `task_output` | 任务输出文本 | `{task_id, text}` |
| `task_completed` | 任务完成 | `{task_id, status, duration_ms}` |
| `tool_call_start` | 工具调用开始 | `{id, name, args, task_id?}` |
| `tool_call_result` | 工具调用结果 | `{id, name, status, output, task_id?}` |
| `text_delta` | 文本增量 | `{text}` |
| `todos_updated` | 任务列表更新 | `{todos: [{content, status}]}` |
| `done` | 流结束 | `{}` |
| `error` | 错误 | `{message}` |

## 12. 数据库表结构

### task_contexts 表

```sql
CREATE TABLE task_contexts (
    context_id VARCHAR(36) PRIMARY KEY,  -- Task UUID
    thread_id UUID NOT NULL,              -- 会话ID (FK → conversations)
    content TEXT NOT NULL,                -- 原始输出内容
    summary TEXT,                         -- LLM摘要 (可选)
    key_data JSONB,                       -- 关键数据 (可选)
    output_types TEXT[],                  -- 输出类型数组
    expected_output TEXT[],               -- 期望输出类型
    token_count INTEGER,                  -- Token数估算
    created_at TIMESTAMP NOT NULL,
    last_accessed_at TIMESTAMP NOT NULL,  -- 滑动过期基准
    expires_at TIMESTAMP NOT NULL,        -- 过期时间
    metadata JSONB                        -- 扩展信息 (file_references等)
);

-- 索引
CREATE INDEX idx_task_contexts_thread ON task_contexts(thread_id);
CREATE INDEX idx_task_contexts_expires ON task_contexts(expires_at);
```
