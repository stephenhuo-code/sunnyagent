# 统计质量分析知识库

## 核心质量工具

### 1. 统计过程控制（SPC）

SPC 通过控制图监控过程是否处于统计受控状态。

**常用控制图类型：**

| 控制图 | 数据类型 | 适用场景 |
|--------|---------|---------|
| X̄-R 图 | 计量型，子组 2-10 | 最常用，监控均值和极差 |
| X̄-S 图 | 计量型，子组 >10 | 大子组，用标准差替代极差 |
| I-MR 图 | 计量型，单值 | 单个测量值，破坏性检验 |
| p 图 | 计数型，不合格品率 | 子组大小可变 |
| np 图 | 计数型，不合格品数 | 子组大小固定 |
| c 图 | 计数型，缺陷数 | 检验单元大小相同 |
| u 图 | 计数型，单位缺陷数 | 检验单元大小可变 |

**控制图判异准则（Nelson 规则）：**
1. 任一点落在控制限外（3σ）
2. 连续 9 点位于中心线同一侧
3. 连续 6 点递增或递减
4. 连续 14 点交替上下波动
5. 连续 3 点中有 2 点落在 2σ 之外（同一侧）
6. 连续 5 点中有 4 点落在 1σ 之外（同一侧）
7. 连续 15 点在 1σ 之内（分层现象）
8. 连续 8 点在 1σ 之外（混合现象）

### 2. 过程能力分析

**关键指标：**

- **Cp（过程能力指数）：** Cp = (USL - LSL) / (6σ)，衡量过程的潜在能力，不考虑偏移
- **Cpk（修正过程能力指数）：** Cpk = min[(USL - X̄)/(3σ), (X̄ - LSL)/(3σ)]，考虑过程偏移
- **Pp / Ppk（过程性能指数）：** 使用总体标准差计算，反映实际过程性能
- **Cpm（Taguchi 能力指数）：** 考虑与目标值的偏移

**能力等级判定：**

| Cpk 值 | 等级 | 评价 | 建议措施 |
|--------|------|------|---------|
| ≥ 2.0 | A++ | 极优 | 可考虑减少检验 |
| 1.67-2.0 | A+ | 优秀 | 维持现状 |
| 1.33-1.67 | A | 良好 | 标准控制 |
| 1.0-1.33 | B | 尚可 | 加强监控，改善过程 |
| 0.67-1.0 | C | 不足 | 必须改善，加严检验 |
| < 0.67 | D | 严重不足 | 停产整改 |

### 3. 质量分析七大工具

1. **帕累托图（Pareto）：** 识别关键少数问题，遵循 80/20 原则
2. **因果图（鱼骨图/石川图）：** 从人、机、料、法、环、测六方面分析原因
3. **直方图：** 观察数据分布形态和过程能力
4. **散布图：** 分析两个变量之间的相关性
5. **检查表：** 系统收集数据的表格工具
6. **控制图：** 监控过程稳定性（见 SPC 部分）
7. **层别法：** 将数据按不同因素分层分析

### 4. 8D 问题解决方法

8D 是系统化的问题解决流程：

| 步骤 | 名称 | 核心内容 |
|------|------|---------|
| D0 | 准备 | 评估是否需要 8D，收集初步信息 |
| D1 | 组建团队 | 成立跨功能小组 |
| D2 | 问题描述 | 用 5W2H 方法精确描述问题 |
| D3 | 临时措施 | 实施围堵行动，保护客户 |
| D4 | 根本原因 | 使用 5Why、鱼骨图等工具分析根因 |
| D5 | 永久纠正 | 制定并验证永久纠正措施 |
| D6 | 实施验证 | 实施措施并验证有效性 |
| D7 | 预防再发 | 系统性预防措施，更新 FMEA/控制计划 |
| D8 | 总结表彰 | 总结经验教训，表彰团队 |

### 5. FMEA（失效模式与效应分析）

**风险优先数 RPN = 严重度(S) × 发生度(O) × 探测度(D)**

评分均为 1-10 分制。新版 AIAG-VDA FMEA 采用 AP（行动优先级）替代 RPN，分为高(H)、中(M)、低(L) 三级。

### 6. 测量系统分析（MSA）

**五性分析：**
- **偏倚（Bias）：** 测量均值与参考值的差异
- **线性（Linearity）：** 不同量程下偏倚的一致性
- **稳定性（Stability）：** 长期偏倚的一致性
- **重复性（Repeatability）：** 同一操作者重复测量的变异
- **再现性（Reproducibility）：** 不同操作者间的变异

**GR&R 判定标准：**
- %GR&R < 10%：测量系统可接受
- 10% ≤ %GR&R ≤ 30%：可能可接受，需综合评估
- %GR&R > 30%：测量系统不可接受，需改善

## 数据分析输出建议

生成质量分析报告时，应包含：
1. 数据概要（样本量、时间范围、数据来源）
2. 统计描述（均值、标准差、最大/最小值）
3. 图形化展示（控制图、直方图、帕累托图等）
4. 过程能力评估（Cp/Cpk/Pp/Ppk）
5. 异常识别和原因分析
6. 改善建议和行动计划
