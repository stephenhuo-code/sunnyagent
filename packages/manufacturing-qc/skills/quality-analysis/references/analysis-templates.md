# 质量分析报告模板

## 过程能力分析报告模板

### 报告结构

1. **报告信息**
   - 产品名称 / 零件号
   - 特性描述 / 规格要求（USL / LSL / Target）
   - 分析日期 / 分析人员
   - 数据来源 / 样本量 / 子组大小

2. **数据统计摘要**
   - 样本量（n）
   - 均值（X̄）
   - 标准差（σ / s）
   - 最大值 / 最小值
   - 全距（Range）

3. **图形分析**
   - 直方图（含规格限和正态分布曲线）
   - 控制图（X̄-R 或 I-MR）
   - 正态概率图

4. **过程能力指标**
   - Cp / Cpk
   - Pp / Ppk
   - 预估不合格率（PPM）

5. **结论与建议**
   - 过程能力等级判定
   - 过程是否受控
   - 改善建议

## 帕累托分析报告模板

### 报告结构

1. **分析范围**
   - 时间段
   - 产品范围
   - 数据来源

2. **缺陷汇总表**
   | 缺陷类型 | 发生次数 | 占比 | 累计占比 |
   |---------|---------|------|---------|
   | 缺陷A | 120 | 40% | 40% |
   | 缺陷B | 75 | 25% | 65% |
   | ... | ... | ... | ... |

3. **帕累托图**
   - 柱状图（按频次降序排列）
   - 累计百分比折线

4. **分析结论**
   - 关键少数问题识别（累计占比 80% 以内的项目）
   - 改善优先级建议
   - 预计改善效果

- 问题发现日期

### D2 — 问题描述
- **What（什么）：** 问题现象描述
- **Where（哪里）：** 发生位置/工位
- **When（何时）：** 首次发现时间
- **Who（谁）：** 涉及人员/班组
- **How（如何）：** 发现方式
- **How many（多少）：** 影响数量/批次
- **Why（为何）：** 为何是问题（对比标准）

## 客诉分析报告模板

### 基本信息
- 客户名称
- 投诉日期 / 编号
- 产品型号 / 批次号
- 投诉数量 / 不良比例

### 问题描述
- 客户反馈的现象
- 附件（图片、视频等）

### 原因分析
- 初步分析
- 深入分析（5Why / 鱼骨图）
- 根本原因确认

### 纠正措施
- 短期措施（围堵）
- 长期措施（纠正）
- 预防措施

### 改善效果跟踪
- 验证时间节点
- 效果数据
- 客户反馈
