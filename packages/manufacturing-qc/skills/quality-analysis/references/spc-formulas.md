## I-MR（单值-移动极差）控制图

**控制限计算：**

I 图：
- UCL = X̄ + 2.66 × MR̄
- CL = X̄
- LCL = X̄ - 2.66 × MR̄

MR 图：
- UCL = 3.267 × MR̄
- CL = MR̄
- LCL = 0

## 过程能力指数计算

**基本公式：**

```
Cp = (USL - LSL) / (6σ)

Cpk = min[(USL - X̄) / (3σ), (X̄ - LSL) / (3σ)]

Pp = (USL - LSL) / (6s)

Ppk = min[(USL - X̄) / (3s), (X̄ - LSL) / (3s)]
```

其中：
- σ（组内标准差）= R̄/d₂ 或 S̄/c₄
- s（总体标准差）= √[Σ(xi - x̄)² / (n-1)]

**单边规格的过程能力：**
- 仅有上限：Cpu = (USL - X̄) / (3σ)
- 仅有下限：Cpl = (X̄ - LSL) / (3σ)

## p 控制图（不合格品率）

**控制限计算：**

- UCL = p̄ + 3√[p̄(1-p̄)/n]
- CL = p̄
- LCL = p̄ - 3√[p̄(1-p̄)/n]（若 <0 则取 0）

其中 p̄ = 总不合格品数 / 总检验数

## GR&R 计算

**%GR&R = (σ_测量系统 / σ_总体) × 100%**

```
σ²_总体 = σ²_零件 + σ²_测量系统
σ²_测量系统 = σ²_重复性 + σ²_再现性
```

**ndc（可分辨类别数）= 1.41 × (σ_零件 / σ_测量系统)**

判定标准：ndc ≥ 5 为可接受
