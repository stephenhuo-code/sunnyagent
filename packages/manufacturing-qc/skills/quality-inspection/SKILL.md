# 制造业质量检验知识库

## 质检流程总览

制造业质量检验贯穿从原材料到成品出货的全过程，包含四个关键环节：

### 1. 来料检验（IQC - Incoming Quality Control）

**目的：** 确保供应商提供的原材料、零部件符合采购规格要求。

**标准流程：**
1. 接收来料，核对送货单与采购订单一致性
2. 外观检查：包装完整性、标识清晰度、有无运输损伤
3. 依据检验规范执行抽样检验或全检
4. 尺寸测量、性能测试、材质验证（视物料类型）
5. 判定合格/不合格，记录检验数据
6. 合格品入库、不合格品隔离标识并启动 MRB 流程

**抽样方案：** 通常采用 GB/T 2828.1 (等同 ISO 2859-1) 计数型抽样检验标准，根据 AQL 值和批量大小确定抽样数量。

### 2. 过程检验（IPQC - In-Process Quality Control）

**目的：** 监控生产过程中的质量状况，及时发现异常。

**标准流程：**
1. 首件检验：生产开始时的首件确认
2. 巡检：按规定频次对生产线进行巡回检查
3. 工序检验：关键工序的专项检查
4. 过程参数监控：温度、压力、速度等工艺参数
5. 发现异常立即停线，启动异常处理流程

**关键控制点：**
- 首件确认必须由 QC 和生产双方签字
- 关键工序设立质量控制点（QCP）
- 过程参数须在控制限内运行
- 巡检记录保留备查

### 3. 成品检验（FQC - Final Quality Control）

**目的：** 确保成品满足产品规格和客户要求。

**标准流程：**
1. 外观检验：表面质量、颜色、标识
2. 尺寸检验：关键尺寸测量
3. 功能测试：产品性能验证
4. 可靠性测试（如需）：寿命、环境、安全测试
5. 包装检验：包装方式、标签、附件完整性
6. 综合判定并出具检验报告

### 4. 出货检验（OQC - Outgoing Quality Control）

**目的：** 出货前的最终确认，确保发货产品合格。

**标准流程：**
1. 核对出货产品与订单一致性
2. 抽样检验外观和关键特性
3. 验证包装和标识符合客户要求
4. 确认产品可追溯性标识
5. 签发出货检验合格证

## ISO 9001 质量管理体系核心要求

### 与质检相关的关键条款

- **7.1.5 监视和测量资源：** 测量设备须经校准/验证，保证测量结果可追溯
- **8.5.1 生产和服务提供的控制：** 建立受控条件，包括监视和测量活动
- **8.6 产品和服务的放行：** 在策划安排的各阶段实施监视和测量
- **8.7 不合格输出的控制：** 识别和控制不合格输出，防止非预期使用或交付
- **9.1.1 监视、测量、分析和评价：** 确定需监视和测量的对象及方法
- **10.2 不合格和纠正措施：** 对不合格采取措施，分析原因并实施纠正措施

### 文件化要求

质检相关必须保留的文件化信息：
- 检验规范/标准（技术文件）
- 检验记录和报告（质量记录）
- 不合格品处理记录
- 纠正措施记录
- 设备校准记录
- 抽样方案及其依据

## AQL 抽样检验速查

**常用 AQL 值：**
- 外观缺陷（Minor）：AQL 2.5 或 4.0
- 功能缺陷（Major）：AQL 1.0 或 1.5
- 严重缺陷（Critical）：AQL 0 或 0.065

**检验水平：**
- 一般检验水平 I：样本量较小，用于破坏性检验或检验成本高的情况
- 一般检验水平 II：最常用的标准检验水平
- 一般检验水平 III：样本量较大，用于质量要求高的情况
- 特殊检验水平 S-1 到 S-4：样本量极小，用于特殊场合

**转移规则：** 正常检验 → 加严检验（连续 5 批中有 2 批不合格）→ 暂停检验（加严检验下连续 5 批不合格）；正常检验 → 放宽检验（连续 10 批合格且过程稳定）
