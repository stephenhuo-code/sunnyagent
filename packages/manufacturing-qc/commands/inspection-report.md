根据用户提供的信息生成标准化质检报告。

## 执行步骤

1. 确定检验类型：IQC（来料检验）、IPQC（过程检验）、FQC（成品检验）或 OQC（出货检验）

2. 收集报告所需信息：
   - 产品名称/型号/零件号
   - 供应商或生产线信息
   - 批次号/批量
   - 检验日期
   - 抽样方案（AQL 值、检验水平、样本量）
   - 检验项目及其规格要求
   - 检验结果数据

3. 如果用户提供了数据文件（CSV、Excel 等），读取并解析数据

4. 按照以下结构生成报告：
   - **报告头**：报告编号、日期、产品信息、供应商/产线信息
   - **抽样信息**：批量、AQL、检验水平、样本量、Ac/Re
   - **检验结果**：各检验项目的规格、实测值、判定结果
   - **数据汇总**：合格数、不合格数、不合格率
   - **综合判定**：整批合格/不合格/待审
   - **不合格项说明**（如有）：缺陷描述、数量、严重等级
   - **处理建议**：合格放行/退货/让步接收/返工等
   - **签字栏**：检验员、审核人、批准人

5. 使用 quality-inspection 技能中的模板和标准确保报告规范性

6. 将报告输出为用户需要的格式（Word 文档或 Markdown 文件）

## 注意事项

- 报告编号建议格式：[检验类型]-[日期]-[流水号]，例如 IQC-20260224-001
- 所有检验项目必须有明确的合格/不合格判定
- AQL 抽样结果需注明 Ac/Re 判定依据
- 如涉及关键特性（CTQ），需在报告中特别标注
- 报告语言应简洁、准确、专业
