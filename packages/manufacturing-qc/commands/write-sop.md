帮助用户编写新的质检 SOP 或优化现有的标准作业程序。

## 执行步骤

1. 确认 SOP 需求：
   - 新编写还是修订现有 SOP
   - 适用的工序/检验类型
   - 适用的产品范围
   - 目标读者（QC 人员技能水平）

2. 如果是修订现有 SOP，读取用户提供的文件，分析当前内容的不足之处

3. 收集 SOP 所需的关键信息：
   - 检验项目和规格要求
   - 使用的检验设备和工具
   - 抽样方案
   - 判定标准
   - 操作环境要求
   - 安全注意事项

4. 按照以下标准结构编写 SOP：

   **文件头部：**
   - 文件编号（建议格式：SOP-QC-[工序代码]-[版本号]）
   - 文件名称
   - 版本号 / 生效日期
   - 编制/审核/批准人
   - 适用范围

   **正文内容：**
   - **目的：** 明确 SOP 要达成的目标
   - **适用范围：** 适用的产品、工序、场所
   - **职责：** 相关人员的职责分工
   - **术语定义：** 专业术语解释（如需）
   - **设备与工具：** 所需检验设备清单及精度要求
   - **操作步骤：** 按顺序逐步描述操作，每步应包含：
     - 操作动作（清晰、可执行）
     - 质量标准/判定依据
     - 记录要求
   - **异常处理：** 发现不合格时的处理流程
   - **记录表单：** 配套的检验记录表格
   - **相关文件：** 引用的标准、图纸、规范

5. 确保 SOP 内容满足 ISO 9001 文件化信息要求

6. 输出为 Word 文档或 Markdown 文件

## 编写原则

- 语言简洁明确，使用祈使句（"将样品放置于..."而非"操作者应将样品放置于..."）
- 每个步骤只描述一个动作，避免复合指令
- 关键参数须有明确的数值和公差
- 配图说明复杂操作（建议用户后续补充实物照片）
- 操作步骤编号清晰，便于培训和审核引用
- 版本控制信息完整
