## 创建领域文件的提示

1. **从最常查询的表开始** - 不要试图记录所有内容
2. **仅为重要列包含列级详情** - 跳过 `created_at` 等明显的列
3. **真实查询示例 > 抽象描述** - 展示而非讲述
4. **突出记录陷阱** - 这些节省最多时间
5. **保持示例查询可运行** - 使用真实的表/列名
6. **明确注明嵌套/结构字段** - 这些容易让人犯错

## 建议的领域文件

需要记录的常见领域（为每个创建单独文件）：

- `revenue.md` - 计费、订阅、ARR、交易
- `users.md` - 账户、认证、用户属性
- `product.md` - 功能使用、事件、会话
- `growth.md` - DAU/WAU/MAU、留存、激活
- `sales.md` - CRM、销售管道、机会
- `marketing.md` - 活动、归因、潜在客户
- `support.md` - 工单、CSAT、响应时间
