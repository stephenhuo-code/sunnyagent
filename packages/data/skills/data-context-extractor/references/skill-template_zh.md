## 自定义说明

生成技能时：

1. **填写所有占位符** - 不要留下任何 `[占位符]` 文本
2. **删除未使用的部分** - 如果他们没有仪表板，删除该部分
3. **添加具体性** - 通用建议不如具体列名和值有用
4. **包含真实示例** - 示例查询应使用实际的表/列名
5. **保持可扫描性** - 大量使用表格和代码块
