# 统计分析技能

描述性统计、趋势分析、异常值检测、假设检验，以及何时对统计声明保持谨慎的指南。

## 描述性统计方法论

### 集中趋势

根据数据选择正确的中心度量：

| 情况 | 使用 | 原因 |
|---|---|---|
| 对称分布，无异常值 | 均值 | 最有效的估计量 |
| 偏态分布 | 中位数 | 对异常值稳健 |
| 分类或序数数据 | 众数 | 非数值的唯一选择 |
| 高度偏斜且有异常值（如每用户收入） | 中位数 + 均值 | 同时报告两者；差距显示偏斜程度 |

**业务指标始终同时报告均值和中位数。** 如果它们显著不同，数据是偏斜的，单独的均值会产生误导。

### 离散度和变异性

- **标准差**：值通常与均值相差多远。用于正态分布数据。
- **四分位距（IQR）**：从 p25 到 p75 的距离。对异常值稳健。用于偏态数据。
- **变异系数（CV）**：标准差 / 均值。用于比较具有不同尺度的指标的变异性。
- **范围**：最大值减最小值。对异常值敏感，但能快速了解数据范围。

### 业务背景下的百分位数

报告关键百分位数以讲述比单独均值更丰富的故事：

```
p1:   最低 1%（下限 / 最小典型值）
p5:   正常范围的低端
p25:  第一四分位数
p50:  中位数（典型用户）
p75:  第三四分位数
p90:  前 10% / 活跃用户
p95:  正常范围的高端
p99:  前 1% / 极端用户
```

**示例叙述**："会话时长中位数为 4.2 分钟，但前 10% 的用户每次会话花费超过 22 分钟，将均值拉高到 7.8 分钟。"

### 描述分布

描述您分析的每个数值分布的特征：

- **形状**：正态、右偏、左偏、双峰、均匀、重尾
- **中心**：均值和中位数（以及它们之间的差距）
- **离散度**：标准差或 IQR
- **异常值**：有多少个，有多极端
- **边界**：是否有自然下限（零）或上限（100%）？

## 趋势分析和预测

### 识别趋势

**移动平均** 平滑噪声：
```python
# 7 天移动平均（适用于具有周季节性的日数据）
df['ma_7d'] = df['metric'].rolling(window=7, min_periods=1).mean()

# 28 天移动平均（平滑周和月模式）
df['ma_28d'] = df['metric'].rolling(window=28, min_periods=1).mean()
```

**周期对比**：
- 周环比（WoW）：与上周同一天比较
- 月环比（MoM）：与前一个月比较
- 同比（YoY）：季节性业务的黄金标准
- 去年同日：比较特定日历日

**增长率**：
```
简单增长：(当前 - 上一期) / 上一期
复合年增长率：(结束值 / 起始值) ^ (1 / 年数) - 1
对数增长：ln(当前 / 上一期)  -- 更适合波动序列
```

### 季节性检测

检查周期性模式：
1. 绘制原始时间序列——首先进行视觉检查
2. 计算星期几平均值：是否有明显的周模式？
3. 计算月份平均值：是否有年度周期？
4. 比较周期时，始终使用同比或同期比较，以避免将趋势与季节性混淆

### 预测（简单方法）

对于业务分析师（非数据科学家），使用简单方法：

- **朴素预测**：明天 = 今天。用作基线。
- **季节性朴素**：明天 = 上周/去年的同一天。
- **线性趋势**：对历史数据拟合直线。仅适用于明显的线性趋势。
- **移动平均预测**：使用尾随平均值作为预测。

**始终传达不确定性**。提供范围，而不是点估计：
- "根据 3 个月趋势，我们预计下个月注册量在 10K-12K 之间"
- 而不是 "我们下个月将获得正好 11,234 个注册"

**何时升级给数据科学家**：非线性趋势、多重季节性、外部因素（营销支出、节假日），或当预测准确性对资源分配很重要时。

## 异常值和异常检测

### 统计方法

**Z 分数法**（用于正态分布数据）：
```python
z_scores = (df['value'] - df['value'].mean()) / df['value'].std()
outliers = df[abs(z_scores) > 3]  # 超过 3 个标准差
```

**IQR 法**（对非正态分布稳健）：
```python
Q1 = df['value'].quantile(0.25)
Q3 = df['value'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
outliers = df[(df['value'] < lower_bound) | (df['value'] > upper_bound)]
```

**百分位法**（最简单）：
```python
outliers = df[(df['value'] < df['value'].quantile(0.01)) |
              (df['value'] > df['value'].quantile(0.99))]
```

### 处理异常值

不要自动删除异常值。而是：

1. **调查**：这是数据错误、真正的极端值，还是不同的群体？
2. **数据错误**：修复或删除（如负年龄、1970 年的时间戳）
3. **真正的极端值**：保留它们，但考虑使用稳健统计（中位数而非均值）
4. **不同群体**：将它们分离出来单独分析（如企业客户与中小企业客户）

**报告您做了什么**："我们排除了 47 条记录（0.3%），交易金额 >$50K，这些代表单独分析的批量企业订单。"

### 时间序列异常检测

检测时间序列中的异常值：

1. 计算预期值（移动平均或去年同期）
2. 计算与预期的偏差
3. 标记超出阈值的偏差（通常是残差的 2-3 个标准差）
4. 区分点异常（单个异常值）和变化点（持续变化）

## 假设检验基础

### 何时使用

当您需要确定观察到的差异是真实的还是可能是由于随机因素造成的时，使用假设检验。常见场景：

- A/B 测试结果：变体 B 真的比 A 好吗？
- 前后对比：产品更改是否真的移动了指标？
- 分群对比：企业客户的留存率真的更高吗？

### 框架

1. **零假设（H0）**：没有差异（默认假设）
2. **备择假设（H1）**：存在差异
3. **选择显著性水平（alpha）**：通常为 0.05（5% 的假阳性概率）
4. **计算检验统计量和 p 值**
5. **解释**：如果 p < alpha，拒绝 H0（有真实差异的证据）

### 常用检验

| 场景 | 检验 | 何时使用 |
|---|---|---|
| 比较两组均值 | t 检验（独立） | 正态数据，两组 |
| 比较两组比例 | 比例 z 检验 | 转化率、二元结果 |
| 比较配对测量 | 配对 t 检验 | 同一实体的前后对比 |
| 比较 3+ 组均值 | 方差分析 | 多个分群或变体 |
| 非正态数据，两组 | Mann-Whitney U 检验 | 偏态指标、序数数据 |
| 类别之间的关联 | 卡方检验 | 两个分类变量 |

### 实际显著性 vs 统计显著性

**统计显著性** 意味着差异不太可能是由于偶然造成的。

**实际显著性** 意味着差异足够大，对业务决策有意义。

差异可能在统计上显著但实际上无意义（在大样本中常见）。始终报告：
- **效应量**：差异有多大？（如 "变体 B 将转化率提高了 0.3 个百分点"）
- **置信区间**：真实效应的可能范围是什么？
- **业务影响**：这转化为收入、用户或其他业务术语是多少？

### 样本量考虑

- 小样本产生不可靠的结果，即使 p 值显著
- 比例的经验法则：每组至少需要 30 个事件才能基本可靠
- 要检测小效应（如 1% 转化率变化），每组可能需要数千个观察值
- 如果您的样本很小，请说明："每组只有 200 个观察值，我们检测小于 X% 的效应的能力有限"

## 何时对统计声明保持谨慎

### 相关不等于因果

当您发现相关性时，明确考虑：
- **反向因果**：也许 B 导致 A，而不是 A 导致 B
- **混杂变量**：也许 C 同时导致 A 和 B
- **巧合**：变量足够多时，虚假相关是不可避免的

**您可以说**："使用功能 X 的用户留存率高 30%"
**没有更多证据您不能说**："功能 X 导致留存率高 30%"

### 多重比较问题

当您测试多个假设时，有些会"显著"是由于偶然：
- 在 p=0.05 下测试 20 个指标意味着约 1 个会是假阳性
- 如果您在找到一个不同的分群之前查看了许多分群，请注意这一点
- 使用 Bonferroni 校正调整多重比较（将 alpha 除以测试次数）或报告运行了多少测试

### 辛普森悖论

聚合数据中的趋势在数据分群后可能会逆转：
- 始终检查结论是否在关键分群中成立
- 示例：总体转化率上升，但每个分群的转化率都下降——因为混合向转化率更高的分群转移

### 生存偏差

您只能分析"存活"到您数据集中的实体：
- 分析活跃用户忽略了流失的用户
- 分析成功的公司忽略了失败的公司
- 始终问："谁不在这个数据集中，他们的加入会改变结论吗？"

### 生态谬误

聚合趋势可能不适用于个体：
- "X 较高的国家 Y 也较高" 不意味着 "X 较高的个人 Y 也较高"
- 将群体级发现应用于个人案例时要小心

### 锚定在特定数字上

警惕虚假精度：
- "下季度流失率将是 4.73%" 暗示的确定性超出了合理范围
- 更喜欢范围："根据历史模式，我们预计流失率在 4-6% 之间"
- 适当舍入："约 5%" 通常比 "4.73%" 更诚实
