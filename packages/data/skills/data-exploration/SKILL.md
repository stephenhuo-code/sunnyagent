# 数据探索技能

系统性方法论，用于分析数据集、评估数据质量、发现模式和理解模式结构。

## 数据分析方法论

### 第一阶段：结构理解

在分析任何数据之前，先了解其结构：

**表级问题：**
- 有多少行和列？
- 粒度是什么（每行代表什么）？
- 主键是什么？它是唯一的吗？
- 数据最后更新时间是什么时候？
- 数据可以追溯到多久以前？

**列分类：**
将每一列分类为以下之一：
- **标识符**：唯一键、外键、实体 ID
- **维度**：用于分组/筛选的分类属性（状态、类型、地区、类别）
- **指标**：用于测量的定量值（收入、计数、时长、得分）
- **时间**：日期和时间戳（created_at、updated_at、event_date）
- **文本**：自由格式文本字段（描述、备注、名称）
- **布尔值**：真/假标志
- **结构化**：JSON、数组、嵌套结构

### 第二阶段：列级分析

对每一列计算：

**所有列：**
- 空值计数和空值率
- 唯一值计数和基数比（唯一值 / 总数）
- 最常见的值（前 5-10 个及其频率）
- 最不常见的值（后 5 个以发现异常）

**数值列（指标）：**
```
最小值、最大值、平均值、中位数（p50）
标准差
百分位数：p1、p5、p25、p75、p95、p99
零值计数
负值计数（如果意外的话）
```

**字符串列（维度、文本）：**
```
最小长度、最大长度、平均长度
空字符串计数
模式分析（值是否遵循某种格式？）
大小写一致性（全大写、全小写、混合？）
前导/尾随空格计数
```

**日期/时间戳列：**
```
最小日期、最大日期
空日期
未来日期（如果意外的话）
按月/周分布
时间序列中的间隔
```

**布尔列：**
```
真值计数、假值计数、空值计数
真值比率
```

### 第三阶段：关系发现

分析完单个列后：

- **外键候选**：可能链接到其他表的 ID 列
- **层次结构**：形成自然下钻路径的列（国家 > 省份 > 城市）
- **相关性**：一起变化的数值列
- **派生列**：似乎从其他列计算而来的列
- **冗余列**：信息相同或几乎相同的列

## 质量评估框架

### 完整性评分

对每一列评级：
- **完整**（>99% 非空）：绿色
- **大部分完整**（95-99%）：黄色——调查空值原因
- **不完整**（80-95%）：橙色——理解原因及其是否重要
- **稀疏**（<80%）：红色——可能无法在没有填充的情况下使用

### 一致性检查

检查：
- **值格式不一致**：同一概念以不同方式表示（"USA"、"US"、"United States"、"us"）
- **类型不一致**：数字存储为字符串，日期格式各异
- **引用完整性**：外键与任何父记录不匹配
- **业务规则违规**：负数量、结束日期早于开始日期、百分比 > 100
- **跨列一致性**：状态 = "completed" 但 completed_at 为空

### 准确性指标

表明准确性问题的危险信号：
- **占位符值**：0、-1、999999、"N/A"、"TBD"、"test"、"xxx"
- **默认值**：单个值的频率可疑地高
- **陈旧数据**：updated_at 显示活跃系统中没有最近的更改
- **不可能的值**：年龄 > 150、遥远未来的日期、负时长
- **整数偏差**：所有值以 0 或 5 结尾（表明是估计，而非测量）

### 时效性评估

- 表最后更新时间是什么时候？
- 预期的更新频率是多少？
- 事件时间和加载时间之间是否有延迟？
- 时间序列中是否有间隔？

## 模式发现技术

### 分布分析

对数值列，描述分布特征：
- **正态分布**：均值和中位数接近，钟形曲线
- **右偏**：高值有长尾（收入、会话时长常见）
- **左偏**：低值有长尾（不太常见）
- **双峰**：两个峰值（表明有两个不同的群体）
- **幂律**：少数非常大的值，许多小的值（用户活动常见）
- **均匀分布**：各范围频率大致相等（通常是合成或随机数据）

### 时间模式

对时间序列数据，查找：
- **趋势**：持续的向上或向下移动
- **季节性**：重复的模式（每周、每月、每季度、每年）
- **星期效应**：工作日与周末的差异
- **节假日效应**：已知节假日前后的下降或峰值
- **变化点**：水平或趋势的突然转变
- **异常值**：打破模式的单个数据点

### 分群发现

通过以下方式识别自然分群：
- 找到具有 3-20 个唯一值的分类列
- 比较各分群值的指标分布
- 寻找具有显著不同行为的分群
- 测试分群是否同质或包含子分群

### 相关性探索

数值列之间：
- 计算所有指标对的相关矩阵
- 标记强相关性（|r| > 0.7）以供调查
- 注意：相关性不意味着因果关系——明确标记这一点
- 检查非线性关系（如二次、对数）

```markdown

**主键**：[列]
**行数**：[近似值，带日期]
**更新频率**：[实时 / 每小时 / 每日 / 每周]
```

### 模式探索查询

连接到数据仓库时，使用以下模式发现模式：

```sql
-- 列出模式中的所有表（PostgreSQL）
SELECT table_name, table_type
FROM information_schema.tables
WHERE table_schema = 'public'
ORDER BY table_name;

-- 列详情（PostgreSQL）
SELECT column_name, data_type, is_nullable, column_default
FROM information_schema.columns
WHERE table_name = 'my_table'
ORDER BY ordinal_position;

-- 表大小（PostgreSQL）
SELECT relname, pg_size_pretty(pg_total_relation_size(relid))
FROM pg_catalog.pg_statio_user_tables
ORDER BY pg_total_relation_size(relid) DESC;

-- 所有表的行数（通用模式）
-- 每个表运行：SELECT COUNT(*) FROM table_name
```

### 数据血缘和依赖

在探索不熟悉的数据环境时：

1. 从"输出"表开始（报告或仪表板使用的）
2. 向上追溯：哪些表为它们提供数据？
3. 识别原始/暂存/数据集市层
4. 绘制从原始数据到分析表的转换链
5. 注意数据在哪里被丰富、过滤或聚合
