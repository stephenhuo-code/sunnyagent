# /create-viz - 创建可视化图表

> 如果你看到不熟悉的占位符或需要检查已连接的工具，请参阅 [CONNECTORS.md](../CONNECTORS.md)。

使用 Python 创建出版级质量的数据可视化。根据数据生成图表，遵循清晰、准确和设计的最佳实践。

## 用法

```
/create-viz <数据源> [图表类型] [额外指令]
```

## 工作流程

### 1. 理解请求

确定：

- **数据源**：查询结果、粘贴的数据、CSV/Excel 文件，或需要查询的数据
- **图表类型**：明确请求的或需要推荐的
- **目的**：探索、演示、报告、仪表板组件
- **受众**：技术团队、高管、外部利益相关者

### 2. 获取数据

**如果已连接数据仓库且数据需要查询：**
1. 编写并执行查询
2. 将结果加载到 pandas DataFrame

**如果数据是粘贴或上传的：**
1. 将数据解析为 pandas DataFrame
2. 根据需要清理和准备（类型转换、空值处理）

**如果数据来自对话中的先前分析：**
1. 引用现有数据

### 3. 选择图表类型

如果用户未指定图表类型，根据数据和问题推荐一个：

| 数据关系 | 推荐图表 |
|---|---|
| 随时间变化的趋势 | 折线图 |
| 跨类别比较 | 柱状图（类别多时用水平条形图） |
| 部分与整体的组成 | 堆叠柱状图或面积图（避免饼图，除非少于6个类别） |
| 值的分布 | 直方图或箱线图 |
| 两个变量之间的相关性 | 散点图 |
| 随时间变化的双变量比较 | 双轴折线图或分组柱状图 |
| 地理数据 | 分级统计图 |
| 排名 | 水平条形图 |
| 流程或过程 | 桑基图 |
| 关系矩阵 | 热力图 |

如果用户未指定，简要解释推荐理由。

### 4. 生成可视化

根据需要使用以下库编写 Python 代码：

- **matplotlib + seaborn**：最适合静态、出版级质量的图表。默认选择。
- **plotly**：最适合交互式图表或用户请求交互性时。

**代码要求：**

```python
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

# 设置专业风格
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_palette("husl")

# 创建适当大小的图形
fig, ax = plt.subplots(figsize=(10, 6))

# [图表特定代码]

# 始终包含：
ax.set_title('清晰、描述性的标题', fontsize=14, fontweight='bold')
ax.set_xlabel('X 轴标签', fontsize=11)
ax.set_ylabel('Y 轴标签', fontsize=11)

# 适当格式化数字
# - 百分比：'45.2%' 而非 '0.452'
# - 货币：'$1.2M' 而非 '1200000'
# - 大数字：'2.3K' 或 '1.5M' 而非 '2300' 或 '1500000'

# 移除图表杂乱元素
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)

plt.tight_layout()
plt.savefig('chart_name.png', dpi=150, bbox_inches='tight')
plt.show()
```

### 5. 应用设计最佳实践

**颜色：**
- 使用一致的、对色盲友好的调色板
- 有意义地使用颜色（而非装饰性地）
- 用对比色突出关键数据点或趋势
- 将不太重要的参考数据变灰

**排版：**
- 描述性标题陈述洞察，而非仅指标（例如 "收入同比增长23%" 而非 "按月收入"）
- 可读的轴标签（如可避免，不要旋转90度）
- 在关键点上添加数据标签以增加清晰度

**布局：**
- 适当的留白和边距
- 图例放置不遮挡数据
- 按值排序类别（而非按字母顺序），除非有自然顺序

**准确性：**
- 柱状图的 Y 轴从零开始
- 没有清晰标注的误导性轴中断
- 比较面板时使用一致的比例
- 适当的精度（不要显示10位小数）

### 6. 保存并展示

1. 以描述性名称将图表保存为 PNG 文件
2. 向用户显示图表
3. 提供使用的代码以便修改
4. 建议变化（不同图表类型、不同分组、缩放的时间范围）
