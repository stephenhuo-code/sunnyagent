# /build-dashboard - 构建交互式仪表板

构建一个自包含的交互式 HTML 仪表板，包含图表、筛选器、表格和专业样式。可直接在浏览器中打开——无需服务器或依赖项。

## 用法

```
/build-dashboard <仪表板描述> [数据源]
```

## 工作流程

### 1. 理解仪表板需求

确定：

- **目的**：高管概览、运营监控、深度分析、团队报告
- **受众**：谁将使用这个仪表板？
- **关键指标**：哪些数字最重要？
- **维度**：用户应该能够按什么筛选或切片？
- **数据源**：实时查询、粘贴的数据、CSV 文件，或示例数据

### 2. 收集数据

**如果已连接数据仓库：**
1. 查询必要的数据
2. 将结果作为 JSON 嵌入 HTML 文件中

**如果数据是粘贴或上传的：**
1. 解析和清理数据
2. 作为 JSON 嵌入仪表板

**如果没有数据只有描述：**
1. 创建与描述的 schema 匹配的真实示例数据集
2. 在仪表板中注明使用的是示例数据
3. 提供替换为真实数据的说明

### 3. 设计仪表板布局

遵循标准仪表板布局模式：

```
┌──────────────────────────────────────────────────┐
│  仪表板标题                         [筛选器 ▼]  │
├────────────┬────────────┬────────────┬───────────┤
│  KPI 卡片  │  KPI 卡片  │  KPI 卡片  │ KPI 卡片  │
├────────────┴────────────┼────────────┴───────────┤
│                         │                        │
│    主要图表              │   次要图表              │
│    （最大区域）          │                        │
│                         │                        │
├─────────────────────────┴────────────────────────┤
│                                                  │
│    详细表格（可排序、可滚动）                     │
│                                                  │
└──────────────────────────────────────────────────┘
```

**根据内容调整布局：**
- 顶部2-4个 KPI 卡片用于头条数字
- 中间部分1-3个图表用于趋势和分解
- 底部可选的详细表格用于下钻数据
- 筛选器根据复杂度放在标题栏或侧边栏

### 4. 构建 HTML 仪表板

生成一个自包含的 HTML 文件，包括：

**结构（HTML）：**
- 语义化 HTML5 布局
- 使用 CSS Grid 或 Flexbox 的响应式网格
- 筛选器控件（下拉框、日期选择器、开关）
- 带值和标签的 KPI 卡片
- 图表容器
- 带可排序表头的数据表

**样式（CSS）：**
- 专业配色方案（干净的白色、灰色，带数据强调色）
- 带微妙阴影的卡片式布局
- 一致的排版（系统字体以快速加载）
- 适应不同屏幕尺寸的响应式设计
- 打印友好的样式

**交互性（JavaScript）：**
- 用于交互式图表的 Chart.js（通过 CDN 引入）
- 同时更新所有图表和表格的筛选器下拉框
- 可排序的表格列
- 图表上的悬停提示
- 数字格式化（逗号、货币、百分比）

**数据（嵌入的 JSON）：**
- 所有数据直接作为 JavaScript 变量嵌入 HTML
- 无需外部数据获取
- 仪表板完全离线工作

### 5. 实现图表类型

使用 Chart.js 实现所有图表。常见仪表板图表模式：

- **折线图**：时间序列趋势
- **柱状图**：类别比较
- **环形图**：组成（当少于6个类别时）
- **堆叠柱状图**：随时间变化的组成
- **混合（柱状+折线）**：数量与比率叠加

### 6. 添加交互性

**筛选器：**
```javascript
// 所有筛选器更新一个中央筛选器状态
// 筛选器变化时图表和表格重新渲染
function applyFilters() {
    const filtered = data.filter(row => matchesFilters(row));
    updateKPIs(filtered);
    updateCharts(filtered);
    updateTable(filtered);
}
```

**表格排序：**
- 点击列标题进行升序/降序排序
- 当前排序列和方向的视觉指示器

**提示框：**
- 图表悬停时显示详细值
- KPI 卡片显示与上一时期的比较

### 7. 保存并打开

1. 以描述性名称保存仪表板为 HTML 文件（例如 `sales_dashboard.html`）
2. 在用户默认浏览器中打开
3. 确认正确渲染
4. 提供更新数据或自定义的说明

## 输出模板

生成的 HTML 文件遵循此结构：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>[仪表板标题]</title>
    <script src="https://cdn.jsdelivr.net/npm/chart.js@4.5.1" integrity="sha384-jb8JQMbMoBUzgWatfe6COACi2ljcDdZQ2OxczGA3bGNeWe+6DChMTBJemed7ZnvJ" crossorigin="anonymous"></script>
    <style>
        /* 专业仪表板 CSS */
    </style>
</head>
<body>
    <div class="dashboard">
        <header><!-- 标题和筛选器 --></header>
        <section class="kpis"><!-- KPI 卡片 --></section>
        <section class="charts"><!-- 图表容器 --></section>
        <section class="details"><!-- 数据表 --></section>
    </div>
    <script>
        const DATA = [/* 嵌入的 JSON 数据 */];
        // 仪表板初始化和交互性
    </script>
</body>
</html>
```

## 示例

```
/build-dashboard 月度销售仪表板，包含收入趋势、热门产品和区域分布。数据在订单表中。
```

```
/build-dashboard 这是我们的支持工单数据 [粘贴 CSV]。构建一个显示按优先级的数量、响应时间趋势和解决率的仪表板。
```

```
/build-dashboard 为 SaaS 公司创建一个模板高管仪表板，显示 MRR、流失率、新客户和 NPS。使用示例数据。
```

## 提示

- 仪表板是完全自包含的 HTML 文件——通过发送文件即可与任何人分享
- 对于实时仪表板，考虑连接到 BI 工具。这些仪表板是时间点快照
- 请求"深色模式"或"演示模式"以获得不同样式
- 你可以请求特定配色方案以匹配你的品牌
