# /validate - 分享前验证分析

> 如果你看到不熟悉的占位符或需要检查已连接的工具，请参阅 [CONNECTORS.md](../CONNECTORS.md)。

在与利益相关者分享之前，审查分析的准确性、方法论和潜在偏差。生成置信度评估和改进建议。

## 用法

```
/validate <要审查的分析>
```

分析可以是：
- 对话中的文档或报告
- 文件（markdown、notebook、电子表格）
- SQL 查询及其结果
- 图表及其底层数据
- 方法论和发现的描述

## 工作流程

### 1. 审查方法论和假设

检查：

- **问题框架**：分析是否回答了正确的问题？问题是否可能被不同地解读？
- **数据选择**：是否使用了正确的表/数据集？时间范围是否合适？
- **人群定义**：分析人群是否正确定义？是否有意外排除？
- **指标定义**：指标是否清晰一致地定义？是否与利益相关者的理解一致？
- **基准和比较**：比较是否公平？时间段、群组规模和上下文是否可比？

### 2. 检查常见分析错误

系统性地审查：

**数据完整性：**
- 可能影响结果的缺失数据（例如，关键字段中的空值、缺失的时间段）
- 数据新鲜度问题（最新数据实际上是否完整还是仍在加载？）
- 幸存者偏差（是否只看了"存活"到分析日期的实体？）

**统计问题：**
- 辛普森悖论（聚合数据与细分数据的趋势相反）
- 在没有支持证据的情况下将相关性表述为因果关系
- 小样本量导致不可靠的结论
- 异常值不成比例地影响平均值（是否应该使用中位数？）
- 多重测试/挑选显著结果

**聚合错误：**
- 由于不当连接导致的重复计数（多对多爆炸）
- 比率计算中的分母错误
- 混合粒度级别（例如，用户级指标与账户级指标平均）
- 确认收入与开票收入与收款收入混淆

**时间相关问题：**
- 比较时未考虑季节性
- 不完整的时期包含在平均值中（例如，部分月份与完整月份比较）
- 数据源之间的时区不一致
- 前瞻性偏差（使用未来信息解释过去事件）

**选择和范围：**
- 有利于特定叙述的精选时间范围
- 未经说明的排除细分
- 分析中途改变定义

### 3. 验证计算和聚合

尽可能抽查：

- 独立重新计算一些关键数字
- 验证小计汇总为总计
- 检查百分比在预期时是否接近100%
- 确认同比/环比比较使用了正确的基准期
- 验证筛选器在所有指标上一致应用

### 4. 评估可视化

如果分析包含图表：

- 轴是否从适当的值开始（柱状图从零开始）？
- 比较图表的比例是否一致？
- 图表标题是否准确描述所显示的内容？
- 可视化是否可能误导快速浏览的读者？
- 是否有截断的轴、不一致的间隔或扭曲感知的3D效果？

### 5. 评估叙述和结论

审查：

- 结论是否由显示的数据支持
- 是否承认了替代解释
- 不确定性是否得到适当传达
- 建议是否从发现中逻辑推导
- 置信度是否与证据强度相匹配

### 6. 建议改进

提供具体、可操作的建议：

- 可以加强结论的额外分析
- 应该注明的注意事项或限制
- 关键点的更好可视化或框架
- 利益相关者会想要的缺失上下文

### 7. 生成置信度评估

在3级量表上评估分析：

**可以分享** — 分析在方法论上是合理的，计算已验证，注意事项已注明。有小的改进建议但没有阻断问题。

**带注意事项分享** — 分析基本正确，但有特定的限制或假设必须向利益相关者传达。列出必需的注意事项。

**需要修改** — 发现了特定错误、方法论问题或遗漏的分析，应在分享前解决。按优先级列出必需的更改。

## 输出格式

```
## 验证报告

### 总体评估：[可以分享 | 带注意事项分享 | 需要修改]

### 方法论审查
[关于方法、数据选择、定义的发现]

### 发现的问题
1. [严重程度：高/中/低] [问题描述和影响]
2. ...

### 计算抽查
- [指标]：[已验证 / 发现差异]
- ...

### 可视化审查
[图表或视觉呈现的任何问题]

### 改进建议
1. [改进及其重要性]
2. ...

### 给利益相关者的必需注意事项
- [必须传达的注意事项]
- ...
```

## 示例

```
/validate 在我发送给高管团队之前审查这份季度收入分析：[分析]
```

```
/validate 检查我的流失分析——我在比较第四季度和第三季度的流失率，但第四季度的测量窗口更短
```

```
/validate 这是一个 SQL 查询及其转化漏斗的结果。逻辑看起来正确吗？[查询 + 结果]
```

## 提示

- 在任何高风险演示或决策之前运行 /validate
- 即使是快速分析也能从完整性检查中受益——只需一分钟就能挽救你的信誉
- 如果验证发现问题，修复它们并重新验证
- 将验证输出与你的分析一起分享以建立利益相关者的信心
