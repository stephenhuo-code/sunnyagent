# /explore-data - 分析和探索数据集


为表或上传的文件生成全面的数据概况。在深入分析之前了解其结构、质量和模式。

## 用法

```
/explore-data <表名或文件>
```

## 工作流程

### 1. 访问数据


**优先级 1：如果上下文中已有可用文件（CSV/Excel）：**

 1. 直接使用 `read_file` 工具读取上下文中列出的文件
 2. 解析文件内容，理解数据结构
 3. 继续进行分析

**先级 2：如果已连接数据仓库 MCP 服务器：**

1. 探索 schema 以找到相关的表和列
2. 编写 SQL 查询以提取所需数据
3. 执行查询并获取结果
4. 如果查询失败，调试并重试（检查列名、表引用、特定方言的语法）
5. 如果结果看起来异常，在继续之前进行完整性检查

**优先级 3：如果未连接数据仓库：**

1. 请用户以以下方式之一提供数据：
   - 直接粘贴查询结果
   - 上传 CSV 或 Excel 文件
   - 描述 schema 以便为他们编写查询
2. 如果为手动执行编写查询，使用 `sql-queries` 技能获取特定方言的最佳实践
3. 获得数据后，继续分析

**如果都没有：**

1. 请用户提供表名（连接他们的数据仓库）或上传文件
2. 如果他们描述了表 schema，提供运行分析查询的指导

### 2. 生成数据概况

运行以下分析检查：

**表级指标：**
- 总行数
- 列数和类型分布
- 近似表大小（如元数据可用）
- 日期范围覆盖（日期列的最小/最大值）

**每列的列级指标：**
- 数据类型（以及是否与预期类型匹配）
- 空值计数和空值率（%）
- 去重计数和基数（去重数/总数）
- 数值列：最小值、最大值、平均值、中位数、标准差、百分位数（p25、p50、p75、p95、p99）
- 字符串列：最小/最大长度、最常见值（前10）、空字符串计数
- 日期/时间戳列：最小值、最大值、按时间段分布
- 布尔列：真/假/空值分布

**将概况呈现为清晰的汇总表**，按列类型分组（维度、指标、日期、ID）。

### 3. 识别数据质量问题

标记潜在问题：

- **高空值率**：空值率 >5% 的列（警告），>20%（警报）
- **低基数意外**：应该是高基数但不是的列（例如，只有50个不同值的 "user_id"）
- **高基数意外**：应该是分类的列但有太多不同值
- **可疑值**：本应为正数却出现负数、历史数据中出现未来日期、明显的占位符值（如 "N/A"、"TBD"、"test"、"999999"）
- **重复检测**：检查是否有自然键以及是否有重复
- **分布偏斜**：可能影响平均值的极端偏斜数值分布
- **编码问题**：分类字段中的大小写混合、尾随空格、格式不一致

### 4. 建议有价值的维度和指标

根据列概况，推荐：

- **最佳维度列**：用于切分数据（具有合理基数的分类列，3-50个值）
- **关键指标列**：用于度量（具有有意义分布的数值列）
- **时间列**：适合趋势分析
- **自然分组**：数据中明显的层次结构
- **潜在连接键**：链接到其他表（ID列、外键）

### 5. 推荐后续分析

建议3-5个用户可以运行的具体分析：

- "按 [时间列] 对 [指标] 进行趋势分析，按 [维度] 分组"
- "对 [偏斜列] 进行分布深入分析以了解异常值"
- "对 [问题列] 进行数据质量调查"
- "在 [指标A] 和 [指标B] 之间进行相关性分析"
- "使用 [日期列] 和 [状态列] 进行群组分析"

## 输出格式

```
## 数据概况：[表名]

### 概览
- 行数：2,340,891
- 列数：23（8个维度、6个指标、4个日期、5个ID）
- 日期范围：2021-03-15 至 2024-01-22

### 列详情
[汇总表]

### 数据质量问题
[标记的问题及严重程度]

### 推荐探索
[后续分析建议的编号列表]
```

## 提示

- 对于非常大的表（1亿+行），分析查询默认使用采样——如需精确计数请说明
- 如果首次探索新数据集，此命令可在编写特定查询之前让你了解全貌
- 质量标记是启发式的——并非每个标记都是真正的问题，但每个都值得快速查看
